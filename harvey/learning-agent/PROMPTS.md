# Messages to paste

## Each batch

Attach about ten emails, with their attachments, then send:

> B01. Here are the next emails from the legal intake mailbox (period: early September). Produce the batch deliverables in the output format. End with END OF BATCH B01.

Change the batch number every time: B01, B02, B03 and so on. Never reuse one.

## If it stops early

> continue

## Optional check after a batch

> Check batch B01. List every item without a thread ID, every reason you inferred rather than saw, and every personal name or email address you wrote. Then give the corrected items only.

## Consolidation

Upload the saved batch files (B01.md to Bnn.md), then send:

> CONSOLIDATE. The attached files are batch outputs B01 to B12. Build the consolidated deliverables in the output format, working only from these files. Start each file with an === FILE: name.md === line. Mark everything status: draft (unverified).
